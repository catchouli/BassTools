The cycle

Pattern per key
Each pass plays every key in fourths. Drone holds the tonic for a bar; scales and modes run an octave up and back down; arpeggios do the same with the chord tones, up to the octave and back. With inversions on, each arpeggio walks through every inversion — a bar each — then a closing root position an octave up. Each key gets as many bars as its line needs. Set a lead-in for a few bars of click before the first note. Nothing is recorded or sent anywhere; the sound is generated live in your browser.
